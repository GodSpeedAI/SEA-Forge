# Private retained candidate algorithm decisions

This supplements preregistration b8f0a569. It resolves private helper questions only; implementation remains held until actual current RED receives independent review and root releases it. Original frozen tests34df remain unchanged.

1. Generation overflow returns its typed outcome and a deep copy of the safe prior state with only stop-scheduling availability. No later generation can be accepted. Ordinal overflow returns its typed outcome and prior copy with retention-unavailable availability; later windows containing only seen IDs can recover. If the refused ordinal-overflow snapshot is terminal, use terminal-retention-failure availability instead. Never change prior metadata, timestamp, generation, ledger or highest ordinal.
2. The previous state is an admitted immutable helper image, including published marker copies. This is an internal caller precondition, not an untrusted external deserializer. Do not add speculative exhaustive prior validation or infer journal completeness from synthetic counter fixtures. Require previous key equality with requested key. Mismatch yields invalid/nil with prior untouched.
3. The input is a well-formed safe RunTracePort snapshot under its existing contract: exact valid UTF8 identities, allowed enums/frame metadata and valid timestamps. This unit does not duplicate the entire port validator. Explicit helper checks remain exact requested snapshot identity, nonnegative total count at least window length, window length at most1024, and no duplicate exact ID in one window; failed checks yield invalid/nil. The helper never normalizes IDs or infers monotonic response totals. Malformed UTF8 is outside this trusted-input guarantee; no custom-port sanitization claim is made.
4. AcceptedAt is exactly acceptedAt.Format(time.RFC3339Nano), preserving its supplied offset. Capture only for accepted replacement; all refusal markers preserve the old timestamp.
5. First terminal overbudget candidate returns rejected/nil. Add no auxiliary retained terminal control to the result; lifecycle owns the actual snapshot/outcome and later scheduling decisions. A prior terminal overbudget candidate returns rejected plus old safe copy with terminal-retention-failure marker, with no candidate payload.
6. Read-unavailable and retention-unavailable prior states may recover with a valid fitting candidate; success resets availability to current. Terminal-retention-failure or stop-scheduling prior states reject further publication and return a deep safe copy preserving their marker. Helper does not own read scheduling or worker retirement.
7. The 1MiB bound covers exactly the canonical retained image, not temporary allocation, heap or RSS. Every prior/result map, slice and optional frame pointer must be independent. Preserve complete lifetime bookkeeping without pruning. Full lifecycle integration must account for its additional retained controls before making a per-poller image bound claim.

These choices require a different source/design critic before implementation release. No new dependency, public interface, persisted schema, authentication rule, Next or SSE integration is authorized. Add no validation infrastructure, error payload retention, or unrelated refactor.
