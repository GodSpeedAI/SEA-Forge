## New fixture cases

Create only `apps/godspeed-casework-go/internal/server/run_observation_manager_failure_test.go`, with new tests under a distinct prefix such as `TestRunObservationManagerFailure`. Keep all existing manager/helper/policy files byte-identical.

1. **Shared real first-read failure is successful A, per-Prepare accounting is distinct.** Start two independently authorized `prepare` calls for the same selected `(case,run,plan-item)` while one real fake `ReadRunTrace` call is held. Prove two different nonnil leases and exactly two refs to one poller/one initializer. Return a real first-read error. Both Prepare calls must return nil error and nonnil cohort leases, unavailable initial observation with no Runs entry, and matching poller failure outcome. The owner counts one logical read start (`ReadsAttempted=1`); the shared waiter counts zero (`ReadsAttempted=0`); capture times and other per-Prepare DTO values need not be byte-identical. Each Prepare's A cleanup may remove only its own exact ref, once. After actual trace-call return and worker `workerDone` JOIN, prove capacity can be reused; while held, prove it cannot. No duplicate logical or physical initialization is allowed. A differs from failed Prepare: auth/guard/cancel/stop/irreducible assembly errors still return zero wrapper/nil lease and perform owned rollback.

2. **Global Stop and one-Prepare rollback have separate lease ownership.** Use two subcases with distinct Prepare calls/leases sharing one initializing poller. (a) Hold both pending, then manager Stop. Each lease's first drain transition removes only that lease's exact ref, each pending Prepare finishes its own operation registration before awaiting its own drain, no waiter double-removes membership, no read starts after Stop wins, and the shared worker is canceled/joined once only after no eligible refs remain. (b) Roll back/cancel exactly one Prepare while the other remains authorized: only the failed lease's ref is removed; the surviving lease ref remains and the worker is not canceled; the survivor receives the one initializer outcome and later drains its own ref. Assert one worker/read and no stranded waiter. Do not model these as one shared lease/drain. Retain the frozen cancellation-survives-initiator case as a regression.

3. **Stop wins before first read; ready and capacity lifecycle.** With a deterministic protocol barrier before the worker's first `ReadRunTrace` start check, race manager Stop against an initializing entry. When Stop wins, assert no port call, no current value, initializer code 4 and phase stopping 2 (or draining 3 if teardown already owns it), exactly one ready resolution to every waiter, typed stopped Prepare results with zero wrapper/nil lease, and no post-stop read start. Then cover an actually started, cancellation-resistant read: hold the fake inside the port until released, prove manager/lease capacity stays occupied through actual fake return and worker `workerDone` JOIN, and prove a new admitted entry is possible only after that join. Do not equate cancellation request with actual read/adapter retirement or join.

4. **Oversized nil-current key is A before poller admission.** Return one successfully decoded, selected summary whose exact opaque key makes the nil-current canonical combined image exceed `1<<20`. Assert `R=1,V=0,A=1,C=0,O=0`, unavailable outcome, no Runs row, and `ReadsAttempted=0`; Prepare succeeds with its nonnil cohort lease but has no poller ref. Assert no poller entry/worker/trace call was created and this is not `capacity_limited`. This is a manager admission assertion; the pure encoder's oversized-key refusal alone does not prove it. If the validated source selector or DTO contract rules out this input, report the exact source rule to root rather than weakening it or fabricating metadata.

5. **Preserve reserve-all-eight before waiting.** Keep the existing frozen `TestRunObservationManagerPollerCapCountsInitializingEntries` unchanged. It launches two eight-run cohorts and requires all 16 trace starts before releasing reads, then proves the 17th initializer is not started. The new fixture must not replace or serialize away this behavior. The source gate also retains the independent rule that the existing actual-read-retirement/drain test keeps capacity until JOIN.
