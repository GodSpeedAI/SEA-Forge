# Stage 3 — canonical CEP-0008 contract and initial profiles: settlement record (2026-10-04)

## Where the contract lives
Repo `GodSpeedAI/canonical-evaluation-protocol` (local `cep`), branch `profiles/godspeed-v1` (36b5ca6), stacked on `slice-0a-cep-semantic-envelope`, which is not yet on `main` (cep OQ-0010, first recorded as OQ-0006 in error). No consumer owns the contract; no new repository was needed because `cep` already held the canonical full-profile schema.

## What exists
- Base: `schemas/cep-semantic-envelope.schema.json` (normative full profile). Not duplicated.
- Profiles (`schemas/profiles/godspeed/*.v1.schema.json`, generated by `tools/generate_godspeed_profiles.py`, each `allOf [base $ref, tightening]`): `semantic_snapshot`, `authority_request`, `authority_decision`, `execution_trace`, `evidence_packet`, `settlement_packet`; plus `world-transition.v1` (primitive for Stage 10).
- Normative text: `spec/profiles/GODSPEED-PROFILES-v1.md`. world_ref in `scope.world_ref` (alias and label optional, non-authoritative); profile declared at `extensions["cep.profile"]`.
- Authority dispositions: allow, deny, escalate, unknown, constrained_allow, boundary, degraded. `boundary` and `constrained_allow` require constraints and a policy basis; `degraded` also requires compensating controls; never a boolean.
- Shared corpus: `schemas/fixtures/godspeed/` (36 files, manifest, lineage chains) generated by `tools/generate_godspeed_fixtures.py` with orphan detection.
- Validators, all passing the same corpus: Python (`src/cep/godspeed.py`, plus `allOf` added to CEP's validator), Rust (`contracts/rust`, jsonschema 0.58.5, typed `Decision`), TypeScript (`contracts/typescript`, Ajv 8.20, types generated from the schemas). The standard Python `jsonschema` library is a fourth independent check.
- world_ref grammar is defined once, in DomainForge; `cep` mirrors the schema pattern and pins DomainForge's golden vectors by hash (`schemas/vendored/world_ref/`).
- DomainForge emission (`feat/cep-snapshot-world-ref`, 2bf2df4, stacked on PR #132): `--world-name/--world-alias/--world-label` bind a snapshot to its world (`scope.world_ref`, `integrity`, `extensions["domainforge.identity"]`, profile declaration). Opt-in; unchanged without the flag. An invalid model is flagged and never pinned.
