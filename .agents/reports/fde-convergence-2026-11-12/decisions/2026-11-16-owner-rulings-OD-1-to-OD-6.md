## Consolidation addendum (same date)

- Backward compatibility is not a requirement: GodSpeed is pre-adoption. Breaking changes are authorized where they simplify, provided all first-party consumers, contracts, tests and docs change together. Compatibility layers, shims and dead code are removed. Historical evidence, security invariants and frozen evaluation records are never broken.
- **Reconciling this with OD-3's "preserve compatibility where feasible":** a protected interface may break, but only contracts-first, with an explicit version change and the migration (or its deliberate absence) stated in the contract. Frozen specs and anchored evidence are never rewritten. The cleaner design wins over keeping a shim.
- Branches: main is the end state in every repository. Valuable or unfinished work is merged, competing implementations are reconciled, and the rest is deleted locally and remotely once the disposition is verified and recorded. The branch ledger is `branch-ledger.md`. Cognate Workbench's capability/plugin integration (skills, MCP servers) is to be finished if it is still relevant.
