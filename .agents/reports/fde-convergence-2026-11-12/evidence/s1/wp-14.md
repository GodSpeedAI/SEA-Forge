### Deviations and findings

- Schema has no "unknown" form for `world_ref`/`semantic_ref`/`declaration_key`. `semantic_ref` comes only from the WP-13 map and only for the `godspeed-fde-sop` world; operations `nav_aim`/`nav_claim` are application elements, not concepts, so the refs are `godspeed-fde-sop::Episode` (row 7.2d, freeze), `godspeed-fde-sop.evidence::Settlement` (7.5a, settle), `godspeed-fde-sop::no_self_settlement` (3.2b, I-2 decision); the operation name goes in `operation`. Any other world records an `unmapped` gap row, no event (test above).
- Unsigned: the schema has no unsigned marker, so `emitter` is omitted and the outbox row carries `"signature": "absent_before_WP-33"`; the AT-05 "check signature" clause is therefore PARTIAL.
- "Authority decisions on that path": the server records no authority decision for `case.record.append` (identity gate only). The only decision made is I-2, so I record it (`dec-NNNN`, owner SEA-Forge) and emit an event for allow and deny. A freeze reports `authority.decision_id: not_required`. `lineage_refs` for a freeze names the source record because there is no decision to name.
- Envelope is checked structurally (profile fields mirror the CEP `execution_trace` fixture); only the extension is validated against the vendored schema, not the full CEP envelope schema.
- "Same durable step": the outbox row is written right after the ledger line, not atomically with it (two files). The gap is closed by `reconcile_events` (run by every delivery pass and `recover`), which rebuilds the row from the ledger (tested by `an_outbox_write_failure...`).
- Default sink is a local spool `interaction-events/<case>.jsonl`; no network transport. Delivery runs inline after each write and ignores failure.
- `actor.role` is the SEA-Forge identity role, not a SOP role.
- Found by the live capture: a repeated `request_id` is answered from the transport correlation record (response `replayed:false`), so contract-level replay is only visible under a new `request_id` with the same `idempotency_key`; the golden replay frame uses that, and the spec note says so.
- The method catalog `authority: case_control` is the nearest existing class; no policy evaluation runs for this verb.
