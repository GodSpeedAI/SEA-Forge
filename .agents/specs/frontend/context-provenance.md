## Derivation decisions

- The existing semantic palette, type stacks, 4px spacing grid, compact row sizes, depth levels, and governed motion values are preserved verbatim.
- The applied UI kit uses the Readiness Overview because the evidence identifies readiness as the first primary-path operational surface.
- The kit demonstrates a degraded but usable state so the interface can show a dominant lawful action, a named limitation, evidence access, and an honestly disabled case-creation path together.
- The focused previews use no external dependencies. The only reusable visual primitives are source-backed workbench components.

## Asset boundary

The copied source contained no logo, app icon, tray icon, avatar, wordmark, imagery, or font binary. None were fabricated. System typography therefore uses the documented Inter and JetBrains Mono stacks with local/system fallbacks.
