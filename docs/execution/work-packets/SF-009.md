## Context

This is the integration slice that connects the fixed backend pipeline (SF-003),
run locator (SF-004), identity (SF-005), and idempotency (SF-006) to the
Workbench's case authoring, horizon, and run record pages.

## Required outcome

An operator completes the primary case journey through the Workbench and
inspects a complete, honestly settled run record.

## Current evidence

- `CaseCreationWorkbench.tsx` — template selection + preflight exist.
- `caseAuthoringMachine.ts` — preflight → commit → recovery state machine.
- SFWP verbs `case.*` and `run.*` are implemented but disconnected from real
  settlement quality.

## Implementation boundaries

- Wire the UI to the real backend responses post-SF-003/004/005/006.
- Ensure `CaseHorizonPage` derives item standing from real trace events.
- Ensure `RunRecordPage` renders the complete canonical run.
- Do not duplicate validators or build a second case subsystem.

## Acceptance scenarios

1. Template → preflight → commit → case created with stable ID.
2. Allow → execute → settle Accepted → run record complete.
3. Deny → no side effect → case shows denial.
4. False success → Rejected in UI.
5. Restart → case and run still inspectable.

## Verification procedure

```sh
cargo test -p sea-forge-server sfwp
cd workbench && bun run check && bun run test
just workbench-check
cargo test --workspace --all-features --locked --no-fail-fast
```

## Integration notes

SF-010 (approval/recovery) extends this slice with human-approval flows.
SF-011 (evidence/reuse) extends it with auditor inspection and capability
promotion. SF-012 (packaged E2E) proves this slice on a real distribution.

## Known traps

- The case machine's stale-precondition rejection and duplicate-commit paths
  must be wired to real SFWP responses, not mocked.
- The run record page must handle both flat and case-owned layouts (SF-004).

## Definition of done

The primary journey reaches an honestly accepted or rejected settlement through
the real Workbench, with a complete inspectable run record that survives restart.
