# RepairAgent Cell fixture

Cross-repository compatibility fixture for the semantic Cell execution path
(ADR-009). `source/` is a copy of DomainForge's
`fixtures/cell_env/repair-agent` model and dependency files. `openshell/` and
`rego/` are the projections of that model, generated by the released
`domainforge-core` 0.21.1 CLI (tag `v0.21.1`, commit
`ddf9e39`) with:

```sh
domainforge project --format openshell --created-at 2026-10-12T00:00:00Z source/model.sea openshell
domainforge project --format rego --created-at 2026-10-12T00:00:00Z source/model.sea rego
```

Do not edit the generated files: `openshell/openshell.lock` and
`rego/provenance.json` record their hashes, and the OpenShell backend refuses a
projection that does not match its lock. Regenerate instead.
