# Temporal Surface

## Overview
The same object or system inspected through its developmental or historical states, composed over the existing operations monitor (`OperationsPage`). The event cursor is the kernel-minted position in time; no history is fabricated. Reads the currently pinned position from `timeVersionController` in `src/spatial/time`.
